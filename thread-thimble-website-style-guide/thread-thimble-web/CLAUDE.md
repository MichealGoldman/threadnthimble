# Instructions for Claude — Thread & Thimble website

Before changing site content or styles, read `BRAND_GUIDE.md` and `design-tokens.css` in this repository. Treat them as the website's brand and styling source of truth.

1. Preserve the established brand colors, fonts, tagline, tone, and official logo assets. Never invent replacement colors, fonts, or logo variants without asking.
2. Use the CSS custom properties in `design-tokens.css` instead of hard-coded colors or unrelated style values. Follow existing architecture/framework conventions.
3. Use Playfair Display Semibold for headings, Montserrat Medium for supporting text, and Caledonia Semi Italic for taglines only when a licensed webfont is available. Ask before introducing a substitute font.
4. Keep the homepage minimal, friendly, and informational. Display `hello@threadnthimble.com` as a working mailto link.
5. **Never add homepage or navigation links to standalone tutorial/video pages.** Those pages are intended to be reached by their direct URLs/printed QR codes. Do not change their routes without explicit approval.
6. Design mobile-first, with accessible contrast, keyboard focus indicators, descriptive alt text, and reduced-motion support.
7. Use approved logo exports rather than attempting to recreate logo lettering or iconography.
8. Do not add e-commerce claims, menus, promotions, analytics, external dependencies, or new features unless requested.
9. When a request conflicts with this guide, flag the conflict and ask for a decision rather than silently overriding the brand system.
10. Keep changes scoped, explain any new design decisions, and update the guide/tokens when the owner approves a permanent change.

If the brand assets or licensed fonts are missing, identify exactly what is needed instead of guessing.
